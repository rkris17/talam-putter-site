## Local preview

From this folder, start the server and leave that terminal open:

```bash
python3 -m http.server 8765
```

Then open:

- Home: http://127.0.0.1:8765/
- Support: http://127.0.0.1:8765/support.html
- Privacy: http://127.0.0.1:8765/privacy.html

Stop the server with Control-C.

App source remains private in `talam-putter-app`.
